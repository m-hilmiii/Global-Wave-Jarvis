    2

    OAuth Onay Ekranına Gmail Adresinizi Ekleyin

    Onay Ekranına Git

    Google Cloud projeniz test modundayken yalnızca "Test Kullanıcıları" listesindeki hesaplar giriş yapabilir. Butona tıklayın, sayfayı aşağı kaydırıp "Test Users (Test Kullanıcıları)" bölümünden "+ ADD USERS" diyerek YouTube kanalınızın bağlı olduğu Gmail adresinizi ekleyip kaydedin.

    Google Güvenlik Uyarısı Çıkarsa Ne Yapmalısınız?

    Yetkilendirme başladığında Google "Bu uygulama Google tarafından doğrulanmadı" uyarısı verebilir. Bu kendi test uygulamanız olduğu için normaldir:

    1. Sol alttaki "Gelişmiş" (Advanced) linkine tıklayın.
    2. En altta beliren "... uygulamasına git (güvenli değil)" linkine tıklayın.
    3. Tüm YouTube izin kutularını (yükleme & görüntüleme) işaretleyip "Devam Et" deyin.
